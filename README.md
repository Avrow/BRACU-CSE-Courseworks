# BRACU CSE Courseworks

This repository contains coursework and lab files for the mandatory courses in the BRAC University CSE curriculum.

## Courses

- [CSE 110](./%23%20CSE%20110) — Programming Language I
- [CSE 111](./%23%20CSE111) — Programming Language II
- [CSE 220](./%23%20CSE220) — Data Structures
- [CSE 221](./%23%20CSE221) — Algorithms
- [CSE 330](./%23%20CSE330) — Numerical Methods
- [CSE 370](./%23CSE%20370) — Database Systems
- [CSE 421](./%23%20CSE421) — Computer Networks
- [CSE 422](./%23CSE%20422) — Artificial Intelligence

## Repository Structure

Each course has its own folder. The folders may contain:

- Assignment and lab solutions
- Jupyter notebooks and Python programs
- SQL queries and database projects
- Reports and reference documents
- Cisco Packet Tracer project files

## How to Use

Open the folder for the required course and then select the relevant lab or assignment. Jupyter notebooks can be opened with Jupyter Notebook, JupyterLab, or Google Colab. Cisco Packet Tracer files require Cisco Packet Tracer.
